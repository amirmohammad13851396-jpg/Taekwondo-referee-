# سامانه داوری آنلاین تکواندو — راه‌اندازی

این بسته یک نسخه اولیه قابل استقرار است؛ اما تا وقتی تنظیمات Firebase و انتشار انجام نشود، لینک عمومی ندارد.

## امکانات
- اتاق مسابقه با کد ۶ کاراکتری
- ورود داوران متعدد با گوشی و نمایش زنده
- درخواست امتیاز ۱ تا ۵، کیونگو و گام‌جوم
- ثبت نهایی هر درخواست پس از تأیید دو شناسه داور متفاوت
- تابلوی قرمز/آبی، تایمر و راندها
- مدیر اتاق می‌تواند نام‌ها و زمان راند را تنظیم کند
- رویدادها و تأییدها در تاریخچه باقی می‌مانند

## راه‌اندازی یک‌باره

### ۱) ساخت پروژه Firebase
1. وارد https://console.firebase.google.com/ شوید و یک پروژه بسازید.
2. در بخش Authentication > Sign-in method، روش **Anonymous** را فعال کنید.
3. در بخش Firestore Database یک پایگاه داده بسازید.
4. در تنظیمات پروژه، یک Web App بسازید و مقادیر config را بردارید.
5. فایل `firebase-config.js` را باز کنید و `YOUR_API_KEY`، `YOUR_PROJECT_ID` و `YOUR_APP_ID` را با مقادیر واقعی جایگزین کنید. `authDomain` و `projectId` هم باید با پروژه خودتان هماهنگ باشند.

### ۲) نصب ابزارها و انتشار
روی کامپیوتر، Node.js 20 یا جدیدتر و Firebase CLI را نصب کنید. سپس داخل همین پوشه اجرا کنید:

```bash
npm install -g firebase-tools
firebase login
firebase use --add
cd functions
npm install
cd ..
firebase deploy
```

در `firebase use --add` پروژه‌ای را انتخاب کنید که ساخته‌اید. هنگام استقرار، Firestore rules، Cloud Functions و Hosting منتشر می‌شوند. اگر Firebase برای فعال‌سازی Cloud Functions درخواست ارتقای طرح پرداختی کرد، باید شرایط و هزینه‌های احتمالی را قبل از ادامه بررسی کنید.

پس از موفقیت، Firebase یک آدرس HTTPS برای سایت نمایش می‌دهد. آن را برای داوران بفرستید. مدیر از همان لینک اتاق می‌سازد؛ سایر داورها کد اتاق و نام خود را وارد می‌کنند.

## نکات مهم
- نسخه فعلی ورود ناشناس Firebase دارد؛ شناسه هر مرورگر/دستگاه جداست. اگر داور با مرورگر یا دستگاه دیگری وارد شود، یک شناسه جداگانه محسوب می‌شود. برای مسابقه رسمی بهتر است ورود داوران با حساب‌های واقعی و مدیریت دسترسی پیاده‌سازی شود.
- کد اتاق برای ورود لازم است؛ آن را فقط با افراد موردنظر به اشتراک بگذارید.
- تایمر فعلی از زمان سرور شروع/توقف می‌گیرد، ولی پایان صفر ثانیه به‌طور خودکار مسابقه را خاتمه نمی‌دهد؛ مدیر باید تایمر را کنترل کند.
- کیونگو در این نسخه به‌صورت شمارنده اخطار نگهداری می‌شود. گام‌جوم برای ورزشکار ثبت‌شده یک امتیاز به حریف می‌دهد.
- این یک نمونه اولیه نرم‌افزاری است و جایگزین تجهیزات یا مقررات رسمی مسابقات نیست. قبل از استفاده در مسابقه واقعی، قوانین جاری فدراسیون و محاسبه امتیازها را با مسئول فنی بررسی کنید.
